FAST PATH
Templated lookup. No embedding, no vector search, no reasoning.
~500 tok 70% of traffic
RAG / SQL
Permission-filtered retrieval, or AST-validated SQL. Cited.
~3,500 tok 20% of traffic
NEURO-SYMBOLIC
Evidence → typed facts → rule engine → fusion → verify.
~15,000 tok 8% of traffic
SECURITY GATE
Terminates. No model participates in the access decision.
0 tok 2% of traffic
Sufficiency check after every step. If the evidence does not support an answer, the orchestrator escalates to a more expensive path within the plan's budget — so a wrong routing guess costs money, never correctness.
